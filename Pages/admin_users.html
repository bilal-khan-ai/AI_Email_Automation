📖 Instructions
User Management:
  • Create User: Enter username, password, and role, then click "Create"
  • Change Password: Click the "🔑 Password" button next to a user
  • Delete User: Click the "🗑️ Delete" button (disables the user, they can't log in)
  • Roles: Admins can manage users, regular users can only use the dashboard
CLI User Management:

You can also manage users via command line:

# Create user
python manage_users.py create username password --role admin

# List users
python manage_users.py list

# Change password
python manage_users.py change-password username newpassword

# Delete user
python manage_users.py delete username
